# Database Fundamentals & SQL Testing

Este repositorio contiene la evidencia técnica y las consultas desarrolladas durante el Sprint 7 del bootcamp de QA Engineering (TripleTen), enfocado en la manipulación y validación de bases de datos relacionales.

## 🛠️ Tech Stack & Herramientas
* **Bases de Datos:** PostgreSQL, SQL (DML / DDL).
* **Consola (CLI):** Conexión a servidores remotos, gestión de directorios y manipulación de archivos de texto.
* **Técnicas de Consulta:** `INSERT`, `UPDATE`, `DELETE`, Funciones de agregación, Filtrado y Ordenamiento.
* **Relaciones (JOINs):** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN` y Diagramas Entidad-Relación (ERD).

## 🎯 Objetivo del Proyecto
Validar la integridad y persistencia de los datos en el backend mediante consultas SQL complejas, uniendo múltiples tablas para extraer información estructurada y simulando verificaciones reales de un entorno de QA.
